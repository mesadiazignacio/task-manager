# Task Manager

> This is a web-based project management application built with a Kanban board structure, designed to help teams organize tasks visually and collaborate efficiently. The platform supports two roles: Manager and Team Members.

- 🧑‍💼 Role-based access for Manager and Team Members
- 🔐 Login system to securely access your project workspace
- 📝 Create, edit, and delete tasks and notes
- 📦 Drag and drop tasks between Kanban columns (To Do, In Progress, Done)
- 📄 Keep project work organized and visible in real-time
